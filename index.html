ℹ 关于 TP X RADAR
情报雷达的运作逻辑与数据管道

这是谁

唐潘（加油T小P / @TPGoFighting）的个人 AI 与前沿工程技术情报雷达。每天从 X 时间线抓取、打分、聚类，筛出最值得关注的动态。

数据流水线

每日定时触发 → ego-browser 抓 X 时间线 → AI 兴趣画像打分 → 生成快照 + 归档 → 自动部署上线 → radar.tpgofighting.top

数据与防丢原则

  • 每次抓取独立归档（archive/YYYY-MM-DD_HHMMSS.json），永不覆盖历史数据
  • 所有推文保留原始 X 地址，直达源发讨论
  • 推文配图与作者头像本地化缓存，在国内网络环境稳定秒开
  • 本地打分规则基于 config/interests.json 的自定义兴趣画像

技术栈

ego-browser (X 抓取) · Node.js (打分流水线) · Graph Paper 响应式设计系统 · Nginx 生产托管
